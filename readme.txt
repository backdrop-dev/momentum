== Installation ==

1. In your admin panel, go to Appearance → Themes and click Add New.
2. Click Upload Theme, choose the theme's zip file and click Install Now.
3. Click Activate.

== Frequently Asked Questions ==

= Where do I change the colors and fonts? =

In `chassis.json` in the theme's folder. To keep your changes through updates, make a child theme with its own `chassis.json`.
